Web приложение "Заметки"<br>
Автор: Щербаков Игорь (is-inbox@yandex.ru)<br>

## ssh ##
git clone git@github.com:igsproj/notes.git<br>

## https ##
git clone https://github.com/igsproj/notes.git<br>

cd notes<br>

Установка модулей<br>
npm i<br>
npm upgrade<br>

Сборка frontend<br>
npm run build<br>

Подключение к БД
Настроить .env (шаблон в .env_sample). Используется postgres<br>

Запуск миграций для БД и приложения<br>
npm start<br>
